Add NAL Network to your home screen for quick access to games, shows, news and your NAL community.

Add it on iPhone or iPad

  1. Open this page in Safari.
  2. Tap Share — the square with an arrow pointing up. It may be inside the browser menu.
  3. Scroll to Add to Home Screen.
  4. Keep the name NAL Network and tap Add.

Add it on Android

  1. Open this page in Chrome.
  2. Tap the three-dot menu.
  3. Choose Add to home screen or Install app, if offered.
  4. Confirm Add or Install. The wording can vary by phone.

Opened inside Facebook, Instagram or a QR scanner? Use its menu to open this link in Safari or Chrome first.

Your browser asks you to confirm adding the icon. Scanning the code alone does not add it.
